## Trio

Use the `trio` project skill through Bash for a second opinion, an independent rebuild against a spec, a long-context read or a factual cross-check. Start with a focused question, keep independent answers out of each other's prompts, and use the supplied checks to evaluate changes. Use the read-only default for questions and reviews. A delegated model should finish its assigned role directly.

To install the skill, copy this integration's `skills/trio/SKILL.md` into `.claude/skills/trio/SKILL.md` in the project. Use the absolute path to the harness script if the checkout lives elsewhere.
